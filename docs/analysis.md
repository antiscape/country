# 原版拆解与优化策略

> 对象：[Geography Quiz: Flags and Capitals](https://www.crazygames.com/game/world-geography-flags-and-capitals)（Fire Flour，Unity 6 WebGL）
> 目标：保留“看旗识国”的核心快感，同时把一次性 quiz 变成能积累、能复习、能长期玩的地理学习产品。

---

## 1. 它到底是什么

不是“地理百科”，而是一个 **强视觉、低阅读量、短局循环** 的 trivia 游戏：

- 玩家看到 **国名 / 日期 / 统计信息**；
- 从一组 **国旗 / 国家 / 首都** 中做选择；
- 答对得分、答错扣命；
- 60 秒或生命耗尽后结算；
- 用金币买 50/50 提示；
- 用“关卡 + 模式 + 锦标赛”提供长期目标。

它的核心不是“知识难度”，而是 **识别速度 + 模式变化 + 即时反馈**。

---

## 2. 核心循环

```text
进入模式
  → 选择关卡
  → 看题（国名/日期/数据）
  → 在 10 个左右的选项中识别
  → 对/错即时反馈
  → 分数、金币、生命、连击变化
  → 继续下一题
  → 结算（星级/关卡解锁）
  → 回到模式选择
```

这个循环很短，单题 3–8 秒，适合网页/移动端的碎片时间。

### 为什么有效

1. **视觉识别比文字回忆容易**：国旗是图形，用户不需要先组织语言；
2. **每题的反馈确定性高**：对错立即可见，学习成本低；
3. **模式变化提供新鲜感**：同一套“选答案”操作，换题目类型就能延长生命周期；
4. **生命 + 计时 + 连击**：制造轻量紧张感；
5. **金币 + 提示**：让玩家在“节省”与“过关”之间做小决策；
6. **关卡星级**：给重复游玩一个明确目标。

---

## 3. 五种模式的结构

| 模式 | 题目刺激 | 答案形式 | 认知能力 |
|---|---|---|---|
| Flags of the World | 国名 | 国旗 | 图形再认 |
| Independence Day | 日期 | 国旗/国家 | 历史联想 |
| Countries of the World | 国家特征/地图 | 国家名 | 地理定位 |
| Population of Countries | 人口比较 | 国家 | 数量直觉 |
| Tournaments | 混合 | 混合 | 综合 + 竞速 |

模式之间共享同一套 UI 和计分，内容生产成本低，这是它内容量看起来很大的原因。

---

## 4. 体验缺口（按影响排序）

### P0：直接影响“玩得下去”

1. **60 秒总计时 + 3 条命 = 双重惩罚**
   - 读题慢、网络卡、手滑都会导致提前出局；
   - 对非英语母语用户尤其不友好。
2. **10 个国旗横向轮播，选项藏在屏幕外**
   - 玩家经常没看到正确选项就选了；
   - 移动端更严重。
3. **答错只告诉“错了”，没有解释**
   - 下一次遇到同一个国家仍然不会；
   - 缺少“错题 → 复习 → 掌握”的闭环。

### P1：影响“愿不愿意第二天再来”

4. 没有每日挑战/连胜；
5. 没有长期成就或可见的掌握进度；
6. 关卡之外没有“学习区”，玩家不知道自己在进步什么；
7. 提示只有 50/50，策略单一。

### P2：影响“愿不愿意推荐给别人”

8. 缺少分享/战绩卡片；
9. 无障碍与键盘支持有限；
10. 没有离线/安装能力；
11. 多语言但缺少双语对照，中文玩家记英文名困难。

---

## 5. 优化原则

1. **降低认知负荷，但不降低挑战**
   - 所有选项可见；难度通过“相似国旗/相近人口/同地区”提升，而不是靠藏选项。
2. **让错误产生学习**
   - 每道错题都进入复习队列；复习答对才移除；熟练度可见。
3. **短局 + 长期目标**
   - 单局 2–4 分钟；每日/锦标赛/成就提供次日理由。
4. **即时反馈要有信息量**
   - 不只说对错，还要给首都、人口、地区、独立日、一条小知识。
5. **移动优先，而不是桌面缩放**
   - 竖屏网格、横屏单屏、底部 Tab、拇指可达的按钮。
6. **所有关键操作可键盘完成**
   - 数字/字母选答案、空格继续、Esc 暂停、? 提示。

## 6. 优先级与实现映射

| 优先级 | 优化 | GEOQUEST 实现 |
|---|---|---|
| P0 | 每题独立计时 | `LEVELS.secs` 16→10 秒，超时扣 1 心 |
| P0 | 选项全部可见 | 桌面 5×2 / 4×2 网格，移动 3 列 |
| P0 | 知识卡 | 答完展示首都/人口/面积/地区/独立日/小知识 |
| P0 | 错题闭环 | `mistakes` + 熟练度 + 复习模式 |
| P1 | 每日挑战 | 日期种子 + 12 题 + 连胜 + 历史最高 |
| P1 | 长期进度 | 6 关 × 3 星 + XP/等级 + 13 成就 |
| P1 | 图鉴/闪卡 | 194 国搜索、筛选、详情、翻卡 |
| P1 | 提示策略 | 50/50、冻结 8 秒、跳过不扣心 |
| P2 | 锦标赛 | 15 题 / 3 赛段 / 4 命 / 8 人 AI 榜 |
| P2 | 双语 | 中文/English 全 UI + 双语副标题 |
| P2 | 分享 | 结果页复制 emoji 战绩 |
| P2 | PWA/离线 | manifest + service worker + 本地国旗 |
| P2 | 无障碍 | ARIA、焦点陷阱、键盘、减少动效 |

## 8. 应该看的数据

如果上线，优先看这些指标，而不是“总答题数”：

- **单局完成率**：开始关卡 → 结算的比例（判断计时/生命是否过严）；
- **次日留存 / 7 日留存**：每日挑战与连胜是否有效；
- **错题复习转化率**：错题 → 进入复习 → 答对移除；
- **平均掌握国家数**：学习价值指标；
- **提示使用率与金币消耗**：经济系统是否健康；
- **模式分布**：哪个模式被玩得最多，哪个模式需要重做；
- **移动端占比与横竖屏完成率**：布局是否真的可用；
- **分享率**：结果页传播能力。

---

## 9. 取舍

- 不做“精确国界轮廓题”：需要大量 GeoJSON 与边界争议处理，首版用“国旗 + 地图定位点”更稳；
- 不做全球排行榜：需要后端、反作弊、账号体系，首版用本地 AI 榜 + 导出存档；
- 不做 15 种语言：先把中英双语体验做完整，i18n 结构保留扩展空间；
- 不做 60 秒总计时：每题计时更公平，也更容易做“时间加成”；
- AI 对手是本地模拟：可以制造锦标赛氛围，但不宣称在线多人。

---

## 10. 一句话总结

原版的优势是 **“图形识别 + 短局 + 模式变化”**；
GEOQUEST 保留这三点，把原版最薄弱的 **“错题沉淀 / 学习反馈 / 选项可见性 / 移动端布局”** 补齐，
并用每日、成就、图鉴、闪卡把一次性 quiz 变成可长期积累的地理学习工具。
